1) 개요

정간뷰("앱")는 정간보 연주·연습, 정간보 만들기, 오선보→정간보 변환, 조율, 장단, 합주실(온라인 합주), 커뮤니티 기능을 제공합니다.

이 방침은 앱이 어떤 정보를 다루고, 어디로 보내며, 무엇에 쓰는지 설명합니다. 앱은 개인정보를 판매하지 않습니다.

2) 기기에만 저장되는 정보

- 녹음: 사용자가 녹음을 시작했을 때만 만들어지며 기기에 저장됩니다(외부로 보내지 않음).

- 선택한 파일의 위치(URI/경로), 앱 설정(템포·그리드·화면 꾸미기 등), 즐겨찾기, 필기 메모.

3) 외부로 보내는 정보

가. 앱 운영 서버(astoc.kr)

- 기기 식별자: Android ID(앱별 기기 식별값)

- 기기 정보: 제조사·모델·Android 버전·보안 패치 수준·빌드 정보·CPU 종류·화면 크기·언어·시간대

- 앱 정보: 앱 버전, 푸시 알림 토큰(FCM)

- 대화명(사용자가 화면 꾸미기에서 입력한 별명)

- 이용 기록: 앱 실행, 악보 열기(곡·파일 이름), 페이지 보기, 조율·장단 사용, 합주실 만들기·참가, 오선보 변환 요청

- 오선보 변환 시 사용자가 고른 악보 파일(MusicXML/이미지)

사용 목적: 서비스 운영과 장애 분석, 변환 결과 알림 전송, 관리자 기기 확인, 이용 통계.

※ 현재 이 서버와의 통신은 암호화되지 않은 HTTP 로 이루어집니다. 서버에 암호화 통신(HTTPS)을 적용한 뒤 앱에서도 전환할 예정입니다.

나. Google Firebase (Firestore, Cloud Messaging, Storage)

- 합주실·커뮤니티: 대화명, 아바타, 합주실 이름, 참가 상태, 연주 진행 상태(페이지·박자·템포 등), 커뮤니티 메시지

- 커뮤니티 첨부 파일: 사용자가 메시지에 직접 첨부한 사진·파일(Firebase Storage 에 저장)

- 앱이 설치 시 임의로 만든 사용자 식별값(합주실·커뮤니티에서 사용자 구분용)

- 푸시 알림 토큰, Firebase 설치 식별값(Firebase SDK 가 알림 전송을 위해 자동 생성)

사용 목적: 실시간 합주 동기화, 커뮤니티, 알림.

다. Open-Meteo (날씨)

- 시작 화면 날씨 효과를 위해 서울의 고정 좌표로 현재 날씨를 조회합니다.

- 사용자 위치 정보는 사용하지 않으며 보내지 않습니다. 일반적인 인터넷 요청처럼 IP 주소가 상대 서버에 전달될 수 있습니다.

라. GitHub (공개 자료 내려받기)

- 곡 목록, 배경음악, 악기 소리 등 공개 자료를 내려받기만 합니다. 사용자 정보는 보내지 않습니다.

4) 권한

- 마이크(RECORD_AUDIO): 조율(음정 분석), 녹음

- 알림(POST_NOTIFICATIONS): 변환 완료 등 알림

- 진동(VIBRATE): 시작 화면 대금을 누를 때 진동 효과(설치 시 자동 허용)

- 인터넷·네트워크 상태: 온라인 기능

- 저장소(Android 9~12 이하 기기에서만): 파일 저장·불러오기

- 포그라운드 서비스(음악 재생): 화면을 꺼도 음원 재생 유지

1) Overview

JeongGanView ("app") provides jeongganbo playback/practice, jeongganbo maker, staff-to-jeongganbo conversion, tuning, rhythm (jangdan), online ensemble rooms, and community features. The app does not sell personal data.

2) Stored only on your device

Recordings (created only when you start recording), selected file references, app settings, favorites, and handwritten notes.

3) Data sent off the device

a. App server (astoc.kr): Android ID; device info (manufacturer, model, Android version, security patch, build info, CPU ABI, screen size, locale, time zone); app version; push token (FCM); nickname; usage events (app open, score opened incl. song/file name, page view, tuning/rhythm use, ensemble create/join, conversion request); score files you upload for conversion.

Purpose: operating the service, troubleshooting, sending conversion notifications, identifying admin devices, usage statistics.

Note: this connection currently uses unencrypted HTTP. We plan to switch to HTTPS once the server supports it.

b. Google Firebase (Firestore, Cloud Messaging, Storage): nickname, avatar, room names, membership status, playback state for ensemble sync, community messages, photos/files you attach to community messages (stored in Firebase Storage), a random user identifier created by the app at install, push token and Firebase installation ID (generated automatically by the Firebase SDK for notifications). Purpose: real-time ensemble sync, community, notifications.

c. Open-Meteo (weather): current weather for a fixed Seoul coordinate for the start-screen effect. No location data is used or sent; your IP address may be visible to the provider as with any web request.

d. GitHub: downloads public content only (song index, background music, instrument samples). No user data is sent.

4) Permissions

Microphone (tuning, recording), Notifications, Vibration (start-screen effect; granted at install), Internet/network state, Storage (Android 12 and below only), Foreground service for media playback.

5) Retention and deletion

On-device data is deleted when you uninstall the app or delete it in the app. To delete data stored on our server or Firebase, contact us; we will delete it without undue delay after verifying the request.
