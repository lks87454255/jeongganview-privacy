1) 개요

정간뷰("앱")는 정간보 연주·연습, 정간보 만들기, 오선보→정간보 변환, 조율, 장단, 풍류 마당(악기별 합주 음원), 합주실(온라인 합주), 커뮤니티, PC 로그인(PC 브라우저에서 정간보 연주·풍류 마당 쓰기) 기능을 제공합니다.

이 방침은 앱이 어떤 정보를 다루고, 어디로 보내며, 무엇에 쓰는지 설명합니다. 앱은 개인정보를 판매하지 않습니다.

2) 기기에만 저장되는 정보

- 녹음: 사용자가 녹음을 시작했을 때만 만들어지며 기기에 저장됩니다(외부로 보내지 않음).

- 선택한 파일의 위치(URI/경로), 앱 설정(템포·그리드·화면 꾸미기 등), 즐겨찾기, 필기 메모.

· 위도·경도 좌표(정확한 위치 권한이면 GPS 수준, 대략 위치만 허용하면 Android 가 흐린 약 2~3km 수준), 위치 정확도·고도(수직 정확도 포함)·속도·방향·측정 시각·측정 방식(GPS/네트워크), 모의 위치 여부

PC 에서 풍류 마당 곡을 열면 연 곡을 기록합니다. PC 로그인은 12시간 뒤 끝납니다.

사용 목적: 서비스 운영과 장애 분석, 변환 결과 알림 전송, PC 로그인 확인과 부정 접속 막기, 관리자 기기 확인, 이용 통계(위치·지역별 이용 통계 포함).

※ 이 서버와의 통신은 모두 암호화(HTTPS)됩니다. 앱은 암호화되지 않은 통신을 쓰지 않습니다.

마. 공개 자료 내려받기: GitHub, Amazon Web Services(CloudFront·S3), 국립국악원

1) Overview

JeongGanView ("app") provides jeongganbo playback/practice, jeongganbo maker, staff-to-jeongganbo conversion, tuning, rhythm (jangdan), Pungryu Madang (per-instrument ensemble audio), online ensemble rooms, community, and PC login (use jeongganbo playback and Pungryu Madang in a PC browser) features. The app does not sell personal data.

2) Stored only on your device

Recordings (created only when you start recording), selected file references, app settings, favorites, and handwritten notes.

3) Data sent off the device

a. App server (astoc.kr): Android ID; device info (manufacturer, model, Android version, security patch, build info, CPU ABI, screen size, locale, time zone); app version; push token (FCM); the public part of a key the app creates on the device (the private key never leaves the device; used to verify signatures for PC login and admin checks); nickname; location — only if you grant the location permission, sent at app start and when the permission is granted: latitude/longitude (GPS-level with precise location, about 2–3 km blurred by Android with approximate location), accuracy, altitude (with vertical accuracy), speed, bearing, fix time, provider (GPS/network), mock-location flag, and the street address (full address line, country, province/city, district, neighborhood, street, building number/name, postal code) plus a region name (e.g. "Seoul Guro-gu"); location is collected only while the app is in use, never in the background; usage events (app open/exit, score opened incl. song/file name, page view, playback, tuning/rhythm use, jeongganbo maker use, Pungryu Madang song opened, viewing ornaments/archive recordings/help, ensemble create/join/leave, conversion request); crash reports (if the app closes unexpectedly, the error details — time, error location, and a short note of what was happening, e.g. the song and position being played — are saved on the device and sent at the next launch; no user content such as recordings, notes or score files); score files you upload for conversion; PC login (when you scan a QR code shown on a PC and approve it, we record the approving device and the PC's IP address, browser information and login time; songs opened in Pungryu Madang on the PC are recorded; a PC login ends after 12 hours).

Purpose: operating the service, troubleshooting, sending conversion notifications, verifying PC logins and preventing abuse, identifying admin devices, usage statistics (including statistics by location/region).

All communication with this server is encrypted (HTTPS). The app does not use unencrypted connections.

b. Google Firebase (Firestore, Cloud Messaging, Storage): nickname, avatar, room names, membership status, playback state for ensemble sync, community messages, photos/files you attach to community messages (stored in Firebase Storage), a random user identifier created by the app at install, push token and Firebase installation ID (generated automatically by the Firebase SDK for notifications). Purpose: real-time ensemble sync, community, notifications.

c. Open-Meteo (weather): current weather and temperature for the start-screen weather effect and the tea-cup steam. If you grant the location permission, the coordinates sent for weather are rounded to one decimal place (about 11 km); otherwise a fixed Seoul coordinate is used. Your IP address may be visible to the provider as with any web request.

d. Device geocoder (Android Geocoder): if you grant the location permission, the app uses the geocoder built into Android to turn your location into a street address. It is handled by the location service installed on your device (usually Google Play services), which may receive the coordinates.

e. Public content downloads — GitHub, Amazon Web Services (CloudFront/S3), National Gugak Center: the app only downloads public content (song index, scores, audio, Pungryu Madang instrument tracks, instrument samples). No user data is sent. Content is fetched from GitHub first and, if that fails, the same content from Amazon CloudFront. National Gugak Center performance recordings are streamed from its server. As with any web request, your IP address may be visible to these servers.

4) Permissions

Microphone (tuning, recording), Camera (photographing staff scores for conversion, reading PC-login QR codes; QR codes are read on the device and no image is sent; score photos are sent only when you request a conversion), Notifications, Vibration (start-screen effect; granted at install), Location (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION, optional: local weather/season effects and admin location statistics with coordinates and address; choosing "approximate" in the system dialog sends only a blurred location; all features work without it and you can turn it off at any time in Settings), Internet/network state, Storage (Android 12 and below only), Foreground service for media playback.

5) Retention and deletion

On-device data is deleted when you uninstall the app or delete it in the app. To delete data stored on our server or Firebase, contact us; we will delete it without undue delay after verifying the request.

If you turn off the location permission, location is no longer sent; location and address data already stored on the server remain until you ask us to delete it.

Server location data (coordinates and address) is kept for 1 year from receipt and then deleted.

Server usage logs, crash reports and PC login records are kept for 1 year from the time they are recorded and then deleted.

Conversion files and results are kept for 1 year from the request; deleting one in the app's conversion history removes it from the list immediately, and it is deleted from the server when the retention period ends.

6) Backup

Android Auto Backup may include settings and recordings; push tokens, admin status and caches are excluded.

7) Children

The app does not knowingly collect personal information from children under the applicable legal age.

8) Changes

We update this policy when features or laws change and revise the "Last updated" date.
